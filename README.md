The Open Education API (OEAPI, formerly OOAPI) is an open REST API standard for exchanging education data — institutions, programmes, courses, offerings, persons and results — between educational institutions, students and suppliers. It was created by a community of Dutch universities, colleges (MBO, HBO, WO) and suppliers, facilitated by SURF and supported via the Npuls programme. OEAPI is a specification rather than a hosted, queryable API: institutions implement their own endpoints from the published OpenAPI specification, with use cases including RIO and eduXchange. Source: https://oeapi.eu/ (fetched 2026-10-09).

## How this profile is made
